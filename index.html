備份與搬移

所有修改都會自動存在這個瀏覽器裡。建議定期匯出 JSON 備份；匯入時可以選擇「合併」或「取代」。舊版（v1）的 JSON 備份也能直接匯入。

單檔帶著走

把目前的詞庫、配方和圖鑑直接嵌進一個新的 HTML 檔，換電腦打開就能繼續用。新檔案有自己獨立的存檔空間，不會和這個檔案互相覆蓋。

給設計文件用

把整本圖鑑匯出成 Markdown，可以直接貼進企劃文件或筆記軟體。

重設

「預設」指的是這個 HTML 檔內建的資料。重設前建議先匯出 JSON 備份。
